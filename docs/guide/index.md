# Deployment Guide

Choose the deployment method that works best for you.

## Dashboard Deployment

Deploy directly from the Cloudflare Dashboard by importing your GitHub repository. Best for first-time setup and manual configuration.

[**Go to Dashboard Deployment →**](/guide/dashboard)

## GitHub Actions Deployment

Set up an automated CI/CD pipeline using GitHub Actions. Every push to the main branch automatically builds and deploys to Cloudflare Workers.

[**Go to GitHub Actions Deployment →**](/guide/action)

## Comparison

| Method | Effort | Automation | Best For |
|--------|--------|------------|----------|
| Dashboard | Low (once) | Manual | First-time deployment |
| GitHub Actions | Medium (setup) | Fully automatic | Production & ongoing updates |
