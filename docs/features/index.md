# Features

Cloud Mail is packed with features for a complete email experience — all running on Cloudflare's edge network.

## 💰 Low Cost

No server required. Deploy to Cloudflare Workers to dramatically reduce hosting costs. The free tier covers most small deployments.

## 💻 Responsive Design

Automatically adapts to desktop and mobile browsers. Built with Vue 3 and Element Plus UI framework.

## 📧 Email Sending

Integrated with Resend for reliable email delivery:
- Bulk email sending
- Inline images in emails
- Attachments
- Send status tracking

## 📊 Data Visualization

Powered by ECharts to visualize:
- System usage details
- Email growth over time
- User statistics

## 🛡️ Admin Features

Full administrative control:
- User management
- Email management
- RBAC (Role-Based Access Control)
- Resource usage limits
- Feature permissions

## 📦 Attachment Handling

Send and receive attachments:
- Stored in Cloudflare R2 object storage
- Download via secure links
- Supports multiple file types

## 🔔 Email Push Notifications

Receive email notifications via:
- **Telegram bot**
- Third-party email forwarding

## 📡 Open API

Programmatic access with REST API:
- Batch user creation
- Multi-condition email queries
- Full API documentation

## 🔢 CAPTCHA Recognition

Uses **Workers AI** to automatically recognize verification codes in received emails.

## 🎨 Customization

Personalize your email service:
- Custom website title
- Custom login background image
- Transparency settings

## 🤖 Turnstile CAPTCHA

Integrated Cloudflare Turnstile to prevent automated/bot registrations.

## 🌐 Internationalization (i18n)

Multi-language support built-in.

## 🚀 More Coming

The project is actively developed with more features on the roadmap.
