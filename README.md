# Cloud Mail Deploy

Documentation site for deploying [Cloud Mail](https://github.com/maillab/cloud-mail) to Cloudflare Workers.

🌐 **Live:** [doc.xinu.my.id](https://doc.xinu.my.id)

## Local Dev

```bash
npm install
npm run docs:dev
```

## Deploy

Push to `main` → auto-deploys to Cloudflare Pages.
